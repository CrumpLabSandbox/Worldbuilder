# Hands (from CognitiveHands)

The kinematic hands, keyboard and motor layer from
[CrumpLabSandbox/CognitiveHands](https://github.com/CrumpLabSandbox/CognitiveHands)
at commit `9e89c02`, copied unchanged so the giant hands at the MEGAzine BBS
computer can type what players type. The cognitive models are not included:
players' key presses go straight to the motor layer.

To update, copy the same files from a newer CognitiveHands commit and note it here.
