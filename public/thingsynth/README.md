# thingsynth (built copy)

A production build of [thingsynth](https://github.com/CrumpLab/thingsynth) with a
small `?embed` option added, used by Worldbuilder's organ stage. It runs as its
own page and exchanges only notes with the game. Code: GPLv3 (see LICENSE), source
at the link above and in SynthLand. The artwork is copyright Matt Crump, all
rights reserved, and is not covered by the GPL.

Built from the thingsynth working copy at commit 55cce2b plus uncommitted changes,
with the embed changes in `web/src/main.ts` and `web/src/style.css`.
